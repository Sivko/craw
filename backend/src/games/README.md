# Модуль игр (Games)

Модуль для управления игровой логикой, матчами, выбором слов и ротацией художника.

## Описание

Модуль `games` предоставляет функциональность для:
- Начала игры в комнате
- Выбора случайных слов из словаря по уровню сложности
- Управления матчами (создание, завершение)
- Проверки правильных ответов
- Ротации художника между раундами
- Начисления очков игрокам
- Управления таймерами матчей

## API Endpoints

### POST /games/:roomId/start

Начало игры в комнате. Только хост комнаты может начать игру.

**Требования:**
- Комната должна быть в статусе `waiting`
- В комнате должно быть минимум 2 игрока
- Не должно быть активного матча

**Ответ:**
```json
{
  "success": true,
  "data": {
    "id": "match_id",
    "roomId": "room_id",
    "drawerId": "user_id",
    "drawerName": "Имя художника",
    "word": "выбранное_слово",
    "difficulty": "easy",
    "startedAt": "2024-01-01T00:00:00.000Z",
    "endedAt": null,
    "timer": 60,
    "timeRemaining": 60
  },
  "error": null
}
```

**События Redis Stream:**
- `room:updates` - событие `game_started`
- `game:events` - события `match_started`, `word_selected`

### POST /games/:roomId/guess

Отправка предположения слова.

**Требования:**
- Комната должна быть в статусе `playing`
- Должен быть активный матч
- Пользователь не должен быть художником

**Тело запроса:**
```json
{
  "guess": "предположение"
}
```

**Ответ:**
```json
{
  "success": true,
  "data": {
    "id": "match_id",
    "roomId": "room_id",
    "drawerId": "user_id",
    "drawerName": "Имя художника",
    "word": "выбранное_слово",
    "difficulty": "easy",
    "startedAt": "2024-01-01T00:00:00.000Z",
    "endedAt": null,
    "timer": 60,
    "timeRemaining": 45
  },
  "error": null
}
```

**События Redis Stream:**
- `game:events` - событие `correct_guess` (с `isCorrect: true/false`)
- При правильном ответе: `match_ended`, `round_started`, `artist_changed`, `word_selected`

### GET /games/:roomId/current

Получение информации о текущем активном матче.

**Ответ:**
```json
{
  "success": true,
  "data": {
    "id": "match_id",
    "roomId": "room_id",
    "drawerId": "user_id",
    "drawerName": "Имя художника",
    "word": "выбранное_слово",
```

## Игровая логика

### Выбор слова

Слово выбирается случайным образом из таблицы `WordDictionary` с учетом:
- Уровня сложности комнаты (`easy`, `medium`, `hard`)
- Активности слова (`isActive: true`)

### Ротация художника

После завершения каждого матча происходит ротация художника:
1. Определяется текущий художник
2. Выбирается следующий игрок по порядку присоединения (циклическая ротация)
3. Создается новый матч с новым художником и новым словом

### Начисление очков

- **Правильный ответ**: +10 очков угадавшему игроку, +5 очков художнику
- **Таймаут**: очки не начисляются

### Таймер

Каждый матч имеет таймер, который устанавливается из настроек комнаты (30-180 секунд). При истечении времени матч автоматически завершается.

## События Redis Stream

### game:events

Типы событий:
- `match_started` - матч начался
- `match_ended` - матч завершился
- `word_selected` - слово выбрано (только для художника)
- `artist_changed` - художник сменился
- `correct_guess` - получено предположение
- `timeout` - время истекло
- `round_started` - начался новый раунд
- `round_ended` - раунд завершился

### room:updates

Типы событий:
- `game_started` - игра началась
- `game_ended` - игра завершилась

## Зависимости

- `PrismaModule` - доступ к базе данных
- `RedisStreamerModule` - публикация событий
- `RoomsModule` - работа с комнатами

## Обработка ошибок

Модуль обрабатывает следующие ошибки:
- `BadRequestException` - некорректный запрос (комната не в нужном статусе, недостаточно игроков и т.д.)
- `NotFoundException` - ресурс не найден (комната, матч, пользователь, слова)
- `ForbiddenException` - недостаточно прав (только хост может начать игру)
